Ticker

40s linear CSS marquee, transform only, no per-frame JavaScript. Pointer and focus hold it; the Pause button is the MECHANISM WCAG 2.2.2 asks for, because a reader who never hovers has no other way to stop it. Reduced motion is a wrapped grid, not a stopped row.
