# references/type
Typefaces, lettering, and how a type scale behaves. The Milligram Macro look, the
JoJo lettering, dither and print texture on type all go here.
Name: `ref_[section]_[property].png`, e.g. `ref_hero_display-weight.png`.
Every file needs its Take only / Ignore / Why lines in ../README.md.
