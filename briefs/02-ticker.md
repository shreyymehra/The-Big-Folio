# 02 — TICKER

## PURPOSE
A retrofuturist structural device between hero and work. Stock-market ticker mechanic — horizontal continuous scroll.

## SPEC `[LOCKED]` — TEXT, NOT LOGOS

**Content is ideas, not client logos.**

Rationale, and it matters: a logo wall mixing real employers (iSelect, Compare the Market) with spec brands (L'Oréal, Absolut, Duolingo) visually implies client relationships that don't exist. Body-copy disclosure does not undo a one-glance impression.

- Condensed or monospace type, `13px`, `letter-spacing 0.14em`
- Gold separators between strings — these count against the accent budget, so use a single hairline glyph, not filled shapes
- Pause on hover
- Reduced-motion: freeze in place, do not remove

## CONTENT `[GAP]`
8–12 strings. Mix of case study titles, category names, philosophy fragments.

```
[GAP: ticker string 01]
[GAP: ticker string 02]
...
```
