# assets/fonts
Licensed webfont files. SHIPS ON THE SITE, so only files your licence covers for web use.
Expected names (the @font-face block in ../base.css looks for these):

- `milligram-macro-extrabold.woff2`   Zetafonts, Milligram Macro ExtraBold
- `yassitf-regular.woff2`             Ingrimayne Type, Yassitf Plain
- `yassitf-bold.woff2`                Ingrimayne Type, Yassitf Bold

Then uncomment the @font-face block under TYPE in assets/base.css.
