# assets/ideas

PNGs for the Ideas magazine on the home page. SHIPS ON THE SITE.
One file per page, named by page number and what it is:

    p01-cover.png  p03-manifesto.png  p04-projects.png ...

Portrait 2:3 (e.g. 1200 x 1800). Stickers and cut-outs to scatter round the
magazine: transparent PNGs named `prop-<thing>.png`.
