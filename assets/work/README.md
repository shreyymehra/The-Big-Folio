# assets/work
Real project imagery. SHIPS ON THE SITE, so only finished, cleared artefacts go here.
One folder per project slug, matching /work/<slug>/:

    vastr/  voicedna/  vrl/  cut-the-noise/  absolutily/  duolingo/  loreal/

Inside each:
- `cover.webp`    the static designed cover, 16:10, at least 2400px wide. No screen recordings.
- `detail-01.webp`, `detail-02.webp` ...  crops that prove a specific decision.
- Source files (.psd, .fig, .pdf) do not go here. Export to .webp first.
