# assets/icons

Phosphor Icons (MIT, https://phosphoricons.com), bold weight, from @phosphor-icons/core@2.1.1.
Inlined into the HTML with class="ico" so they take currentColor; these files are the sources.
Tool icons for the Ideas desk stickers go here too: `figma.svg`, `claude.svg` ...

## Floating navigation marks (home hero)
The five drifting marks are drawn stand-ins until Shrey's own files arrive. Drop them here,
one per destination, transparent background, roughly square, and they replace the drawn marks:

    nav-work.svg   nav-ideas.svg   nav-me.svg   nav-faq.svg   nav-contact.svg

SVG preferred; PNG at 400px or more also works. Each keeps its label, drift and hover behaviour.
